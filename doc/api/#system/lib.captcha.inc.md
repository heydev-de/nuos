## CAPTCHA Class

The `captcha` class provides a simple yet secure CAPTCHA (Completely Automated Public Turing test to tell Computers and Humans Apart) mechanism for the PWNC Web Platform. It generates image-based challenges to verify human interaction, preventing automated bot submissions.

This class relies on the GD library for image manipulation and uses a daily rotating secret key to enhance security. CAPTCHA images are generated dynamically and returned as base64-encoded PNG data URIs, eliminating the need for temporary file storage.

---

### Properties

| Name      | Default | Description                                                                                     |
|-----------|---------|-------------------------------------------------------------------------------------------------|
| `secret`  | `NULL`  | Daily rotating secret key used to generate and verify CAPTCHA codes.                            |
| `length`  | `4`     | Number of characters in the CAPTCHA. Adjustable, but must match the number of character images. |
| `enabled` | `FALSE` | Boolean flag indicating whether CAPTCHA generation and verification are available.              |

---

### `__construct()`

#### Purpose
Initializes the CAPTCHA system. Checks for required GD library support and loads or generates a daily secret key.

#### Parameters
None.

#### Return Values
None. Sets the `enabled` property to `TRUE` if all requirements are met.

#### Inner Mechanisms
1. Checks if the GD extension is loaded and supports PNG.
2. Retrieves the current secret and its creation date from the cache.
3. If the secret is outdated (older than today), generates a new one using `unique_id()` and updates the cache.
4. Sets `enabled` to `TRUE` only if all conditions are satisfied.

#### Usage Context
Automatically called when the class is instantiated. Should be used at the start of a session or form-handling logic.

#### Example
```php
$captcha = new \cms\captcha();
if ($captcha->enabled) {
    // CAPTCHA is available for use
} else {
    // Fallback: CAPTCHA not supported; proceed without it
}
```

### `create()`

#### Purpose
Generates a new CAPTCHA image and verification code.

#### Parameters
None.

#### Return Values
- **Array** on success:
  - `code` (string): Verification code to be stored server-side (e.g., in session).
  - `image` (string): Base64-encoded PNG data URI of the CAPTCHA image.
  - `width` (int): Width of the image in pixels.
  - `height` (int): Height of the image in pixels.
- **FALSE** if CAPTCHA is not enabled.

#### Inner Mechanisms
1. Generates a random lowercase string of length `$this->length`.
2. Creates a verification code using `hash32()` with the string and daily secret.
3. Creates a blank image canvas sized to fit all characters.
4. For each character:
   - Loads a pre-rendered PNG image from `CMS_IMAGES_PATH/captcha/`.
   - Applies random rotation (if `imagerotate` is available).
   - Centers and pastes the character onto the canvas.
5. Applies obfuscation by inverting colors in the lower half of the image.
6. Converts the image to pure black and white to prevent shape recognition via grayscale analysis.
7. Outputs the image as a PNG, encodes it in base64, and returns the result.

#### Usage Context
Used when rendering a form that requires human verification. The returned `code` should be stored in the session, and the `image` can be embedded directly in HTML.

#### Example
```php
$captcha = new \cms\captcha();
$data = $captcha->create();
if ($data) {
    $_SESSION["captcha_code"] = $data["code"];
    echo '<img src="' . $data["image"] . '" alt="CAPTCHA" width="' . $data["width"] . '" height="' . $data["height"] . '">';
    echo '<input type="text" name="captcha_key" placeholder="Enter the code">';
}
```

### `verify($key, $code)`

#### Purpose
Validates a user-provided CAPTCHA response against the expected verification code.

#### Parameters

| Name   | Type   | Description                                                                 |
|--------|--------|-----------------------------------------------------------------------------|
| `key`  | string | User-provided response (e.g., from a form input).                           |
| `code` | string | Expected verification code (previously generated by `create()` and stored). |

#### Return Values
- **TRUE** if the CAPTCHA is disabled or the response is valid.
- **FALSE** if the response is invalid.

#### Inner Mechanisms
1. If CAPTCHA is disabled, returns `TRUE` (allows bypass).
2. Computes a hash of the lowercase `key` concatenated with the daily secret.
3. Compares the computed hash with the provided `code` using `streq()` (constant-time comparison).

#### Usage Context
Used during form submission to verify that the user entered the correct CAPTCHA text.

#### Example
```php
$captcha = new \cms\captcha();
if ($captcha->verify($_POST["captcha_key"], $_SESSION["captcha_code"])) {
    // CAPTCHA verified; process form
    unset($_SESSION["captcha_code"]);
} else {
    // Invalid CAPTCHA; show error
    echo "Invalid verification code. Please try again.";
}
```

---

### Notes

- **Character Images**: The class expects individual PNG files named `0.png` to `z.png` in `CMS_IMAGES_PATH/captcha/`. These should be pre-rendered, clear, and monochromatic.
- **Security**: The daily secret rotation limits the window of opportunity for replay attacks.
- **Accessibility**: This CAPTCHA is visual-only. Consider providing an audio alternative or alternative verification methods for accessibility compliance.
- **Performance**: Image generation is CPU-intensive. Avoid generating CAPTCHAs on every page load; only generate when needed (e.g., on form display).
