## sha256.js

This file implements the SHA-256 cryptographic hash function in pure JavaScript. It provides a single function `sha256` that computes the SHA-256 digest of a given ASCII string and returns the result as a lowercase hexadecimal string.

The implementation follows the standard SHA-256 algorithm specification, including message padding, message schedule generation, and compression function rounds. It is designed to be self-contained with no external dependencies, making it suitable for use in environments where native crypto APIs are unavailable or restricted.

### sha256(str)

Computes the SHA-256 hash of the provided string.

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `str` | `string` | The input string to hash. Must consist of ASCII characters only (byte values 0–255). |

#### Return Values

| Type | Description |
|------|-------------|
| `string` | A 64-character lowercase hexadecimal string representing the SHA-256 digest of the input. |
| `undefined` | Returned if the input string contains non-ASCII characters (byte values > 255). |

#### Inner Mechanisms

1. **Rotation Helper**: The internal `rot(v, n)` function performs a 32-bit right rotation on integer `v` by `n` bits using bitwise operations.
2. **Initial Hash Values**: The `hash` array holds the initial eight 32-bit words defined by the SHA-256 standard.
3. **Round Constants**: The `k` array contains the 64 round constants specified in the SHA-256 standard.
4. **Message Padding**:
   - Appends a `0x80` byte (`\x80`) to the input string.
   - Appends zero bytes (`\0`) until the total length modulo 64 equals 56.
5. **Message Parsing**:
   - Converts the padded string into an array of 32-bit words (`w`), stored in big-endian order.
   - Appends the original message length in bits as two 32-bit words at the end of `w`.
6. **Hash Computation**:
   - Processes the message in 512-bit (16-word) blocks.
   - For each block, expands the 16-word input into a 64-word message schedule using the standard SHA-256 recurrence relation.
   - Performs 64 rounds of compression using the round constants and message schedule.
   - Updates the running hash state after each block.
7. **Hexadecimal Output**:
   - Converts the final 256-bit hash state into a 64-character lowercase hexadecimal string.

#### Usage Example

```javascript
var hash = sha256("hello world");
console.log(hash); // Outputs: "b94d27b9934d3e08a52e52d7da7dabfac484efe37a5380ee9088f7ace2ef25b6"
```

This example computes the SHA-256 hash of the string `"hello world"` and logs the resulting hexadecimal digest. This is useful for generating checksums, implementing client-side validation, or creating deterministic identifiers from text input.
