## SHA-256 Hashing Utility

Pure JavaScript implementation of the SHA-256 cryptographic hash function. This utility provides client-side hashing capabilities without external dependencies, adhering to PWNC's zero-dependency philosophy.

### Function: `sha256(str)`

#### Purpose
Generates a SHA-256 hash of the input string. The function processes the input through the SHA-256 algorithm and returns the resulting hash as a hexadecimal string.

#### Parameters

| Name | Type   | Description                          |
|------|--------|--------------------------------------|
| str  | string | Input string to be hashed. Must be a UTF-8 compatible string. Non-ASCII characters are not supported. |

#### Return Values

| Type   | Description                          |
|--------|--------------------------------------|
| string | 64-character hexadecimal SHA-256 hash of the input string. |

#### Inner Mechanisms
1. **Padding**: The input string is padded with a `0x80` byte followed by null bytes (`\0`) to ensure its length is a multiple of 64 bytes (512 bits).
2. **Message Schedule**: The padded message is split into 32-bit words. Additional words are generated using bitwise operations (rotations and shifts).
3. **Compression**: The algorithm processes each 512-bit block using 64 rounds of bitwise operations, modular additions, and logical functions (Ch, Maj, Σ0, Σ1).
4. **Hash Computation**: Intermediate hash values are updated iteratively. The final hash is derived by concatenating the 32-bit words of the hash state.
5. **Hex Conversion**: The resulting 256-bit hash is converted to a 64-character hexadecimal string.

#### Usage Context
- **Client-Side Security**: Useful for hashing sensitive data (e.g., passwords) before transmission to the server.
- **Data Integrity**: Verify the integrity of files or messages by comparing hashes.
- **Token Generation**: Generate unique tokens or identifiers based on input data.

### Usage Example

#### Scenario: Hashing a Password Before Submission
```javascript
// Hash a user's password before sending it to the server
const password = "userSecurePassword123";
const hashedPassword = sha256(password);

// Send the hashed password to the server for verification
fetch('/api/login', {
    method: 'POST',
    body: JSON.stringify({ password: hashedPassword }),
    headers: { 'Content-Type': 'application/json' }
})
.then(response => response.json())
.then(data => console.log('Login successful:', data));
```

#### Explanation
1. The `sha256` function processes the plaintext password into a hashed value.
2. The hashed password is transmitted to the server, reducing the risk of exposing the plaintext password during transmission.
3. The server compares the received hash with a stored hash (e.g., in a database) to authenticate the user.
